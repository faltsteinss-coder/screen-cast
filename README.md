# ScreenCast — экран и звук Android-смартфона на ТВ-приставку по Wi-Fi

Одно приложение для обоих устройств: на приставке выбирается «Принимать», на телефоне — «Передавать».

## Требования
- Телефон: Android 7.0+ (звук — Android 10+).
- Приставка: Android / Android TV 7.0+. Не подходит для tvOS, Tizen, webOS и приставок на Linux.
- Оба устройства в одной локальной сети. Лучше 5 ГГц или приставка по кабелю.

## Сборка APK
Вариант 1, Android Studio: Open → папка ScreenCast → дождаться синхронизации →
Build → Build APK(s). Файл: app/build/outputs/apk/debug/app-debug.apk

Вариант 2, без установки программ (GitHub):
1. Создайте репозиторий и загрузите в него содержимое папки ScreenCast
   (вместе со скрытой папкой .github; файл settings.gradle должен лежать в корне).
2. Вкладка Actions → Build APK → Run workflow.
3. Скачайте артефакт ScreenCast-apk из завершённого запуска.

## Установка
На приставку: через флешку и файловый менеджер, либо `adb connect IP && adb install app-debug.apk`.
Разрешите установку из неизвестных источников.

## Использование
1. Приставка: «Принимать трансляцию» — появятся IP и код.
2. Телефон: «Передавать экран», выберите приставку (или введите IP), введите код.
3. «Начать трансляцию», разрешите захват. На Android 14+ выберите «Весь экран».
4. Остановка — кнопкой в приложении или нажатием на уведомление.

## Ограничения
- Netflix, банковские и другие защищённые приложения дают чёрный экран и/или тишину.
- Звук на телефоне продолжает играть: убавьте громкость мультимедиа (на части моделей это
  может заглушить и передаваемый звук).
- Трафик не шифруется, код защищает только подключение. Используйте в своей домашней сети.
- Гостевые сети и «изоляция клиентов» на роутере блокируют подключение.
- Порт: TCP 47000.
